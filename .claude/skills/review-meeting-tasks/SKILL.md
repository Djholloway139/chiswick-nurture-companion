# /review-meeting-tasks

Read AGENTS.md first. Use live discovery, guides/browser.md and guides/recording.md throughout.

Discover the meeting review queue read and dedicated proposal decision capabilities. Read each selected proposal and its context. Ask which of approve, edit then approve, or reject Bela wants for that individual item. For edits, show the exact revised proposal before approval.

Use the dedicated meeting proposal decision capability only if its live description supports the requested decision. Never use generic task status or labels. If absent, incomplete or refused, use guides/browser.md to perform that proposal's live workflow. Read the resulting proposal and any created task, then say the verified result plainly.

Confirmation: Bela confirms each proposal's exact decision separately. This command permits meeting proposal decisions; accepting an audit or document review remains Bela's action. For that exception, say so, open the live page and hand over.

Reads need no tracking task or recording. Read back every write and say its result plainly; record only failed or partial writes as task comments under guides/recording.md.
