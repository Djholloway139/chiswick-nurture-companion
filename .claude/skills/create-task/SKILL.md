# /create-task

Read AGENTS.md first. Use live discovery, guides/browser.md and guides/recording.md throughout.

Discover task creation, task editing and live people lookup capabilities. Resolve the intended person from live workspace choices; ask about ambiguity. Ask for missing required details from the live schema, without inventing dates.

Show the proposed task and assignee. If creation supports assignment, use it. Otherwise create then assign through the live editing capability, confirming both writes separately. Verify the task and assignment after each step; report partial success if assignment fails. If any capability is absent, incomplete or refused, use guides/browser.md.

Confirmation: Bela confirms each creation or assignment. Read the saved task and say the verified result plainly.

Reads need no tracking task or recording. Read back every write and say its result plainly; record only failed or partial writes as task comments under guides/recording.md.
