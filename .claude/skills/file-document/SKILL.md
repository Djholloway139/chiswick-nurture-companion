# /file-document

Read AGENTS.md first. Use live discovery, guides/browser.md and guides/recording.md throughout.

Discover document upload, live type and governance vocabulary, metadata and replacement capabilities. Read their descriptions and schemas, then follow guides/filing.md in order. Verify a replacement target and explain any retention consequence using live information; never promise recoverability.

If a capability is absent, incomplete or refused, use guides/browser.md for that filing step. Confirmation: Bela confirms file safety, each upload, replacement and metadata change. Reread the saved document and say the result plainly. Record failed or partial writes under guides/recording.md. Use /rollback-document if he wants a previous replacement restored.

Reads need no tracking task or recording. Read back every write and say its result plainly; record only failed or partial writes as task comments under guides/recording.md.
