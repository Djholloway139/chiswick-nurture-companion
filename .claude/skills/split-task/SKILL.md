# /split-task

Read AGENTS.md first. Use live discovery, guides/browser.md and guides/recording.md throughout.

Read the original through the live task detail capability. Verify it is an ordinary task, not an audit or review task. Agree the replacement tasks, owners and dates with Bela. Use /create-task for each replacement, confirming and reading back every creation and assignment.

Keep the verified new task references. Only after all replacements exist and are assigned as agreed, confirm and post a linking comment on the original and verify it. Then separately confirm cancelling the original, use the live ordinary task editing capability and read it back. Include the original reference on the replacements with confirmed comments. Never cancel early or claim the whole split worked after a partial failure. Check an unknown result before retrying.

If any capability is absent, incomplete or refused, use guides/browser.md for that step. Confirmation: every replacement, linking comment and cancellation needs Bela's specific approval and verified result said plainly.

Reads need no tracking task or recording. Read back every write and say its result plainly; record only failed or partial writes as task comments under guides/recording.md.
