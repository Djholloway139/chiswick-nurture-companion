# /calendar

Read AGENTS.md first. Use live discovery, guides/browser.md and guides/recording.md throughout.

Agree the date range and timezone. Discover live task-by-date and audit-cycle calendar capabilities. Read both, follow all live continuation, and distinguish task deadlines from audit dates. If either capability lacks the requested range, filters or continuation, say which result is incomplete.

If absent, incomplete or refused, use guides/browser.md for the corresponding calendar information. Confirmation: reads need normal Nurture approval. Any requested date change is a separate confirmed task change, never an inferred reschedule. Do not change audit status or definitions.

Reads need no tracking task or recording. Read back every write and say its result plainly; record only failed or partial writes as task comments under guides/recording.md.
