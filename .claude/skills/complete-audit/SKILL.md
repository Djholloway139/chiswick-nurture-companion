# /complete-audit

Read AGENTS.md first. Use live discovery, guides/browser.md and guides/recording.md throughout.

Discover audit cycle listing, full pack, definition, document reading and evidence attachment capabilities. Read the current pack, stages, requirements, instructions, questions, previous documents and evidence. Use live original downloads and continuation as needed; use guides/browser.md for absent, incomplete or refused capabilities. Never invent questions or a procedure. Answers belong in the returned document where the live pack requires that. Bela prepares safe counts and summaries; follow /file-document and guides/filing.md for returned documents and evidence.

For stage return, read the live stage and reason. Confirm the exact return, then use only a dedicated stage-return capability or the live browser workflow. For formal deferral, require Bela's explicit reason, show the exact named requirement and consequence, confirm, then use only a dedicated deferral capability or its live browser workflow. Reread each saved change and say the result plainly. Record failed or partial writes under guides/recording.md. Never emulate either action with generic task status or labels.

Confirmation: each attachment, stage return and formal deferral with reason needs Bela's specific approval. Accepting a review and closing an audit are exceptions Bela must do himself. Say that plainly, open the page found through get_tutorial and hand over; verify only after he returns control. Never submit these actions through any tool or browser automation.

Reads need no tracking task or recording. Read back every write and say its result plainly; record only failed or partial writes as task comments under guides/recording.md.
