# /run-report

Read AGENTS.md first. Use live discovery, guides/browser.md and guides/recording.md throughout.

Discover the live workspace reporting capabilities. Agree the reporting period and read the returned definitions, coverage and freshness. Obtain completed, overdue, per-person/team figures and the weekly summary when available. Never infer missing numbers, treat an absent summary as zero, or present a different period as requested.

If a capability or requested figure/period is absent, incomplete or refused, use guides/browser.md to read the live reporting page. State any remaining gap. Confirmation: read-only reporting needs normal Nurture approval; ask before generating, saving or sharing anything and read it back and say its result plainly.

Reads need no tracking task or recording. Read back every write and say its result plainly; record only failed or partial writes as task comments under guides/recording.md.
