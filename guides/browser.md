# Browser fallback

## First time: set up Claude in Chrome

Do this only when a job first needs the browser. Check whether Claude in Chrome tools are available. If not, walk Bela through it one step at a time, waiting for each:

1. Install [Chrome](https://www.google.com/chrome/) if he doesn't have it.
2. In his own Chrome, install the [Claude in Chrome extension](https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn) and sign in to it with his own Claude account.
3. Sign in to https://app.nurtureoutreach.com himself. Never watch or handle his password.
4. In Claude, open **Settings**, then **Customize**, then **Connectors**. Find **Claude in Chrome**, choose **Configure** and turn it on.
5. Check you can see a safe Nurture page. If not, say what is missing and hand over to Bela, or ask him to tell Dan.

## Using it

Use Claude in Chrome in Bela's own signed-in Chrome. Discover the page address and purpose through `get_tutorial`, then read the live page. Check it belongs to the fixed Nurture host and the workspace Bela confirmed. Follow what is visible now. Never store navigation positions, layouts or dashboard labels in the kit.

If the capability is absent, incomplete or refused, explain that before switching. Bela may use his dashboard access beyond his key's access. Show the exact proposed change and ask him to confirm before making it. Read the saved result and say it plainly. Reads need no tracking task or comment; failed or partial writes follow guides/recording.md. A general yes to browser access does not confirm future changes.

Accepting a review and closing an audit are Bela's exceptions. Open the discovered page, tell him plainly that he must do this himself, and hand over. Verify the resulting state only after he returns control. Meeting proposals, stage return and formal deferral use the dedicated command instructions.

If page discovery, the extension or the signed-in session is unavailable, state the missing part. Ask Bela to open the page himself and hand over; do not guess an address or claim automated fallback is available. Pause for sign-in, key handling, unexpected sensitive data and any workspace mismatch. Never use another browser session or account to avoid a refusal.
